# data/raw

Original data, exactly as it arrived. Never edited, never cleaned in place.

The authoritative copy belongs in shared, backed-up storage. Anything here is a
working copy and is not tracked by git.

Set these files to read-only so they cannot be changed by accident:

- macOS / Linux: `chmod -w data/raw/*`
- Windows: right-click the file, Properties, tick Read-only
